Kore Autopub

Outil interne de la chaîne Kore — Science & Mystères

Kore Autopub est un outil privé qui publie automatiquement les vidéos de vulgarisation scientifique de Kore sur les propres comptes de la chaîne (YouTube, Instagram, TikTok), via les API officielles de ces plateformes.

Il n'est pas proposé au public : seuls les comptes appartenant à Kore l'utilisent.
